# 三线课表

考研 / 六级 / 赚钱 三线并行的手机课表：逐项打卡、随时改、到点提醒。

打开：**https://htedot.github.io/kebiao/**

手机上打开后，浏览器菜单 →「添加到主屏幕」，之后就跟 App 一样。

## 有什么

- **今日**：现在该做什么 + 当天清单，点圆圈打卡
- **课表**：7 天 × 8:00–23:00 一屏，点色块直接改时间/星期/备注
- **打卡**：连续天数、近 7 天完成率、8 周热力图、三条线各打多少次
- **设置**：通知权限、导出 `.ics` 进手机日历（关浏览器也响）、备份/还原

## 数据

只存在你自己手机浏览器的 localStorage 里，没有账号、没有服务器、不上传。换设备或清缓存前，在设置页导出备份。

详细说明见 [使用说明.md](使用说明.md)。
